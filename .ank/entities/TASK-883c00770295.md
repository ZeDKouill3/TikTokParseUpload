Première tâche de SPEC-5e50 (lire `ank show SPEC-5e50` et ADR-58c0) : R1 (comptes YouTube), R8 (heure de Paris), socle de clipper/youtube.py. PAS la publication ni les stats (tâches suivantes).

## À faire
1. clipper/accounts.py : champ `service` (`tiktok` | `youtube`) sur chaque compte de publication ; comptes existants sans champ = `tiktok`, migration automatique à la lecture (testée). L'écran Comptes permet d'ajouter un compte YouTube (choix du service), affiche le service sur chaque compte.
2. « Se connecter » d'un compte YouTube : même mécanisme que TikTok (Chrome NORMAL lancé avec `--user-data-dir=state/browser/<id>`, pas Playwright : la connexion Google comme TikTok refuse un navigateur piloté), page https://studio.youtube.com .
3. Vérification « prêt à publier » YouTube (comme SPEC-e500 pour TikTok) dans clipper/youtube.py : ouvrir https://studio.youtube.com sur le profil ; connecté si l'URL devient `studio.youtube.com/channel/<UC...>/...` et que la navigation affiche « Votre chaîne <nom> » (ARIA : navigation > img dont le nom = nom de chaîne, texte « Votre chaîne <nom> ») ; enregistrer nom de chaîne et id UC... sur le compte ; non connecté (page de connexion Google accounts.google.com) = pas prêt, raison affichée. Une dialog « Bienvenue dans YouTube Studio » (bouton « Continuer ») apparaît à la 1re visite : la fermer par « Continuer » si présente.
4. Repères dans clipper/assets/youtube_selectors.toml (nouveau, même forme que tiktok_selectors.toml), pour l'instant : url studio, motif d'URL de chaîne, texte « Votre chaîne », dialog bienvenue + bouton « Continuer ». Repères relevés en réel le 2026-10-03 (YouTube Studio en français) : marquer ces clés « vérifié 2026-10-03 ».
5. R8 heure de Paris : clipper.browser lance tout contexte Playwright piloté (TikTok et YouTube) avec `timezone_id="Europe/Paris"` (et locale fr-FR si déjà le cas) ; dans clipper/tiktok.py, `schedule_later` convertit la cible en `ZoneInfo("Europe/Paris")` au lieu de `target.astimezone()` (fuseau du PC, ici Londres) ; idem partout où une date est saisie dans une page. Le PC de l'utilisateur est réglé sur Londres : ne jamais dépendre du fuseau du PC.
6. Un seul compte piloté à la fois tous services confondus (verrou dans clipper.browser si le verrou actuel est propre à TikTok).

## Tests (sans navigateur, réseau ni YouTube)
Migration comptes sans service -> tiktok ; ajout compte youtube via API web ; vérification prêt : fausse page connectée (URL channel + « Votre chaîne X ») -> prêt + nom X + id UC ; fausse page Google login -> pas prêt avec raison ; dialog bienvenue fermée ; timezone_id Europe/Paris passé au lancement ; schedule_later TikTok avec PC simulé en Europe/London : la date saisie = heure de Paris ; verrou : deux comptes de services différents ne sont jamais pilotés en même temps.
