Le pipeline consomme le quota Max de l'utilisateur via claude -p (moments/parts en opus, le reste en sonnet) sans aucune mesure. Chaque appel de clipper.llm.ask doit laisser une trace : usage (moments, vision...), modèle, tokens entrée/sortie/cache, coût USD si le backend le donne (claude -p --output-format json renvoie usage et total_cost_usd), durée. Écrit en JSONL sous workspace/<video_id>/llm_usage.jsonl, plus un résumé par usage à la fin de chaque étape dans le journal. Aucune valeur inventée : un backend qui ne donne pas l'usage écrit null (ADR-ad2e).
