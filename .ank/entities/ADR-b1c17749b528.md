## Contexte
Un LLM local 7B sur 4 Go de VRAM juge mal ce qui est viral et ne tient pas 2-3 h de transcription en contexte. L'utilisateur a un abonnement Claude Max 5x et autorise Claude dans le pipeline (révise la note initiale « pas de Claude pour l'instant »).

## Décision
Claude intervient là où il faut du jugement :
- transcription : vocabulaire initial (noms propres depuis titre/description) et correction des noms propres sans toucher aux timecodes ;
- choix des moments (transcription entière + signaux + images clés + exemples de feedback) ;
- points de coupe des parties ;
- mots mis en valeur dans les sous-titres ;
- description des images clés autour des moments candidats ;
- classification de la mise en page d'un plan pour le recadrage ;
- titre, légende, hashtags, texte d'accroche ;
- contrôle qualité du clip rendu.
Le lourd (vidéo, audio, whisper, suivi de visages frame par frame, rendu) reste local.
Modèle fort pour moments et coupes, modèle rapide pour le volume (images, QA), réglable en config.

## Conséquences
- Tests : backend factice (fake) dans clipper.llm, aucun test n'appelle le vrai Claude.
- Quota partagé avec les sessions Claude Code de l'utilisateur ; erreurs quota/réseau = attente et re-essai (voir ADR mode).
