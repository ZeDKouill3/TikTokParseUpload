## Contexte
La v1 était une GUI customtkinter lourde, mise à jour depuis des threads (bug). L'utilisateur préfère une page web locale.

## Décision
- `python -m clipper serve` lance FastAPI (uvicorn) sur localhost.
- Page : coller une URL YouTube, suivre la progression par étape, revoir les moments proposés (aperçu, ajuster début/fin, accepter/refuser), lancer le rendu, voir les clips.
- Progression via polling ou SSE ; le traitement tourne dans un worker séparé du thread HTTP.

## Conséquences
L'interface est remplaçable sans toucher au pipeline, et le pipeline tourne sans elle (CLI).
