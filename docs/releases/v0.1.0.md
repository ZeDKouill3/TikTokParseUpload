## Ce que fait clipper

`clipper` transforme une vidéo longue (YouTube ou VOD Twitch,
`twitch.tv/videos/<id>`) en clips verticaux (9:16) sous-titrés, prêts à
publier sur TikTok. La vidéo est découpée en moments forts par un LLM
(sélection notée selon une grille, avec un mode jury à cinq juges pour la
sélection automatique), chaque moment devient un clip (ou plusieurs parties
s'il est trop long), sous-titré mot par mot.

Deux formats de recadrage vertical :
- **letterbox** (défaut) — zoom fixe, titre d'écran en haut, sous-titres
  dans la bande floue du bas.
- **stream** (`layout = "stream_auto"`) — pour les vidéos avec facecam :
  facecam fixe agrandie en haut, jeu en bas, jamais de bascule dans un clip.

Option : **appel à l'abonnement** (désactivé par défaut) — pseudo de la
chaîne sous le titre d'écran, carte « Abonne-toi ! » sur les dernières
secondes, lien et hashtags dans la description ; un fichier de config par
chaîne (`python -m clipper run <url> --config ma-chaine.toml`).

Deux modes d'exécution :
- **review** (défaut) — tu valides chaque moment proposé (accepter /
  refuser / ajuster les bornes) via l'interface web locale
  (`python -m clipper serve`) ou en ligne de commande, avant le rendu.
- **auto** — le pipeline va jusqu'au bout seul, un contrôle qualité
  automatique remplace la revue humaine ; une erreur transitoire (quota
  Claude, réseau) remet la vidéo en file d'attente au lieu d'abandonner ou
  de produire un résultat dégradé en silence.

Le pipeline tourne en local (transcription, détection de scènes/visages,
rendu ffmpeg sur ta machine) ; seules les étapes qui demandent du jugement
(choix des moments, titres/légendes, contrôle qualité...) passent par
Claude.

## Prérequis

- **Python 3.11**, géré par [uv](https://docs.astral.sh/uv/).
- **[ffmpeg](https://ffmpeg.org/)** (et `ffprobe`) dans le PATH.
- **[Claude Code CLI](https://docs.claude.com/claude-code)** (`claude`)
  dans le PATH et connecté — backend LLM par défaut.
- **GPU NVIDIA** optionnel (accélère la transcription et le rendu) ; sans
  GPU, tout tourne sur CPU, plus lentement.

## Installation et première commande

```powershell
uv venv
uv pip install -e ".[test]"
```

(`uv` est obligatoire, pas `pip` seul — voir `README.md`.) Ou lance
`tools/setup.ps1`, qui installe et vérifie les prérequis.

```powershell
copy config.example.toml config.toml
python -m clipper run <url-youtube-ou-vod-twitch>
python -m clipper serve   # interface web locale, http://127.0.0.1:8000
```

Voir `docs/GUIDE.md` pour le détail des commandes, des modes et de la
configuration.

## Mesures réelles

Sur une RTX 3050 Laptop (4 Go VRAM), vidéo `7VaA8XUKrAY` (67 min, format
letterbox) : passage du 2026-09-30 qui reprend à l'étape `moments`
(download/transcribe/scenes/audio déjà faits lors d'un passage précédent,
réutilisés du cache, ADR-b16b) — **8 clips produits, 8/8 passés au contrôle
qualité** (un avertissement non bloquant sur un clip), coût LLM de 3,64 $
(73 appels) pour les étapes `moments` -> `qa` (vocabulaire/correction de
transcription non inclus, non rejoués dans ce passage). Pic VRAM mesuré à
1,68 Go sur une autre vidéo de l'échantillon (137 min), loin des 4 Go de la
carte. Détail complet des durées par étape, des coûts et de la méthode :
`docs/benchmarks/rtx3050.md`.

## Limites connues

- **Pré-version** : pas de garantie de stabilité de l'interface en ligne de
  commande ni du format de configuration.
- **Chaque vidéo consomme du quota Claude** ; le coût dépend de la durée de
  la vidéo, du nombre de clips et du mode de sélection (voir
  `docs/benchmarks/rtx3050.md` pour des ordres de grandeur mesurés, et
  `workspace/<video_id>/llm_usage.jsonl` pour le détail par passage).
- **La grille de notation des moments est calée sur la parole** : un moment
  fort sans dialogue marquant (par exemple un moment purement visuel ou
  musical) peut être sous-noté.
- **Aucune publication automatique sur TikTok** : clipper produit les clips
  et leurs métadonnées (titre, légende, hashtags), la mise en ligne reste
  manuelle.
