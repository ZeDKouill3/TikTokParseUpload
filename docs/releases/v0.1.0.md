# clipper v0.1.0 (pré-version)

Première pré-version de `clipper` : transforme une vidéo YouTube longue ou
un VOD Twitch en clips verticaux sous-titrés, prêts à publier sur TikTok —
sélection des moments, montage et légendes assistés par LLM, le reste
(transcription, détection de scènes/visages, rendu) tourne en local.

> ⚠️ **Pré-version.** Pas encore de garantie de stabilité de l'interface en
> ligne de commande ni du format de configuration. À utiliser en local, sur
> ses propres vidéos.

## Points forts

- **Pipeline complet en 12 étapes**, reprenable par étape (aucune étape déjà
  faite n'est rejouée sauf `--force`), du téléchargement au contrôle qualité.
- **Sélection des moments par LLM notée selon une grille**, avec un mode
  jury à cinq juges pour la sélection automatique et un apprentissage à
  partir des décisions passées.
- **Deux formats verticaux** : letterbox (zoom fixe, défaut) et stream
  (facecam fixe agrandie en haut, jeu en bas), sans bascule dans un clip.
- **Deux modes d'exécution** : `review` (tu valides chaque moment) et `auto`
  (contrôle qualité automatique, aucune erreur ne produit un résultat
  dégradé en silence — elle remonte, est journalisée, ou remet la vidéo en
  file d'attente).
- **Coût et usage LLM journalisés par vidéo** (`llm_usage.jsonl`) : pas de
  boîte noire sur la consommation de quota Claude.
- **Tout tourne sur CPU pour les tests** ; GPU NVIDIA optionnel qui accélère
  transcription et rendu.

## Nouveautés par thème

### Entrée YouTube / Twitch

Téléchargement via yt-dlp, au mieux en 1080p mp4 : URL YouTube classique ou
VOD Twitch (`twitch.tv/videos/<id>`).

### Transcription GPU

Transcription mot par mot par faster-whisper (`BatchedInferencePipeline`,
`batch_size=8` par défaut), device résolu automatiquement CPU/CUDA par
`clipper.gpu` (jamais codé en dur), avec correction de la transcription et
du vocabulaire de noms propres par LLM.

### Sélection des moments et jury

Les moments forts sont choisis par LLM et notés selon une grille
(`rubric.toml`, SPEC-0eec). En mode `auto`, un jury à cinq juges (rétention,
spectateur, monteur, avocat, conformité) tranche, avec débat déclenché sur
écart de score et apprentissage à partir des décisions passées, sans
uniformisation des juges.

### Formats letterbox / stream

Deux formats de recadrage vertical : **letterbox** (zoom fixe, titre
d'écran en haut, sous-titres dans la bande floue du bas) et **stream**
(`layout = "stream_auto"`, facecam détectée une fois, agrandie en haut, jeu
en bas, jamais de bascule dans un clip). Le format `crop` (suivi de visage)
reste disponible comme option figée.

### Sous-titres et titres

Sous-titres mot par mot (.ass) avec emphase choisie par LLM, titre d'écran
et accroche générés par clip.

### CTA abonnement

Appel à l'abonnement optionnel, désactivé par défaut (SPEC-6a47) : pseudo
de chaîne discret sous le titre d'écran, carte de fin « Abonne-toi ! » sur
les dernières secondes, ligne d'appel et hashtags supplémentaires dans la
description — réglé par un fichier de config par chaîne (`--config`).

### Contrôle qualité

Contrôle qualité automatique (`qa`) avant chaque clip : résolution, durée,
silence de tête, image noire. Un clip n'est prêt que si `qa.is_ready` le
confirme.

### Modes review / auto

**review** (défaut) : tu acceptes, refuses ou ajustes chaque moment proposé
avant le rendu, via l'interface web ou en ligne de commande. **auto** : le
pipeline va jusqu'au bout seul, `qa` remplace la revue humaine ; une erreur
transitoire (quota Claude, réseau) remet la vidéo en file d'attente au lieu
d'abandonner ou de produire un résultat dégradé en silence (ADR-ad2e).

### Interface web

`python -m clipper serve` sert une page statique locale (FastAPI,
`clipper/web/`) : liste des vidéos, décision sur les moments, aperçu des
clips, lancement du rendu. Aucune logique de traitement vidéo/audio/LLM
côté serveur (ADR-09ad).

### Observabilité `llm_usage.jsonl`

Chaque appel LLM (réussi ou définitivement refusé) est journalisé dans
`workspace/<video_id>/llm_usage.jsonl` : usage, modèle, tokens, tokens de
cache, coût, durée — une ligne JSON par appel, pour connaître la
consommation réelle d'une vidéo sans deviner.

## Installation

### Depuis la wheel jointe à cette release

```powershell
uv venv
uv pip install clipper-0.1.0-py3-none-any.whl
clipper init   # ecrit config.toml et rubric.toml (grille embarquee) dans le dossier courant
```

La wheel fournit la commande `clipper`, en plus de `python -m clipper`.

### Depuis les sources

```powershell
uv venv
uv pip install -e ".[test]"
```

`uv` est **obligatoire** (pas `pip` seul) : `pyproject.toml` déclare sous
`[tool.uv] override-dependencies` un contournement qui force un seul paquet
OpenCV installé (`opencv-contrib-python`) — `mediapipe` et `scenedetect` en
réclament chacun un différent, et `pip` seul ignore ce réglage. Ou lance
`tools/setup.ps1`, qui installe et vérifie les prérequis.

## Démarrage rapide

```powershell
clipper init   # deja fait si tu viens de l'installation ci-dessus
clipper run <url-youtube-ou-vod-twitch>
clipper serve   # interface web locale, http://127.0.0.1:8000
```

Voir `docs/GUIDE.md` pour le détail des commandes, des modes et de la
configuration.

## Configuration

Chaque étape déclare ses réglages dans le `CONFIG_DEFAULTS` de son module ;
`config.toml` valide chaque table `[<étape>]` contre ce dict. Pour une
chaîne tierce (ex. republier les meilleurs moments d'un·e streameur·se), un
preset dédié se passe avec `--config` :

```powershell
python -m clipper run https://www.twitch.tv/videos/<id> --config presets/ma-chaine.toml
```

```toml
[render]
cta_enabled = true
cta_handle = "twitch.tv/ma_chaine"

[captions]
cta_line = "Abonne-toi sur Twitch pour plus de lives !"
```

Détail complet des sections (`[transcribe]`, `[moments]`, `[jury]`,
`[reframe]`, `[render]`, `[llm]`...) : `docs/GUIDE.md`.

## Prérequis

- **Python 3.11**, géré par [uv](https://docs.astral.sh/uv/).
- **[ffmpeg](https://ffmpeg.org/)** (et `ffprobe`) dans le PATH.
- **[Claude Code CLI](https://docs.claude.com/claude-code)** (`claude`)
  dans le PATH et connecté — backend LLM par défaut.
- **GPU NVIDIA** optionnel (accélère la transcription et le rendu) ; sans
  GPU, tout tourne sur CPU, plus lentement.

## Limites connues et feuille de route

- **Pré-version** : pas de garantie de stabilité de l'interface en ligne de
  commande ni du format de configuration.
- **Chaque vidéo consomme du quota Claude** ; le coût dépend de la durée de
  la vidéo, du nombre de clips et du mode de sélection (voir
  `docs/benchmarks/rtx3050.md`).
- **La grille de notation des moments est calée sur la parole** : un moment
  fort sans dialogue marquant peut être sous-noté.
- **Aucune publication automatique sur TikTok** : clipper produit les clips
  et leurs métadonnées, la mise en ligne reste manuelle.
- **Surveillance d'une chaîne Twitch** (nouvelles VOD détectées
  automatiquement) : pas encore couverte, sur la feuille de route.
- **Banc whisper `large-v3-turbo` vs `small`** (vitesse, VRAM, qualité FR) :
  en cours, choix du modèle par défaut à confirmer une fois terminé.
